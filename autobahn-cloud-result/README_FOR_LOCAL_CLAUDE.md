# Результат облачных заданий A–G для Autobahn

Эта папка — итог семи заданий из `CLOUD_TASKS.md`, собранный в одно целое. Исходная точка — коммит `main` **05c86a4** («Задания для Cloud Code»).

В облаке не было Unity, поэтому **ничего не собрано и не запущено**. Код скомпилирован компилятором C# (Roslyn) против справочных сборок UnityEngine 2022.3. По сравнению с `main` новых ошибок нет, кроме API Unity 6 (`linearVelocity`, `PhysicsMaterial`) и типов URP (`AntialiasingQuality`): их просто нет в сборках 2022.3, а в самом проекте на Unity 6 они корректны.

## Что внутри

- `files/` — итоговые версии всех изменённых и новых файлов (A+B+C+D+E+F+G вместе), с путями от корня проекта. Их можно просто скопировать поверх проекта. Список файлов — в `changed-files.txt`.
- `patches/` — те же изменения в виде патчей:
  - `ALL-A-to-G.patch` — всё сразу, от `main` 05c86a4;
  - `A-streaming.patch` → `B-grid.patch` → `C-physics-near.patch` → `D-lod-mobile.patch` — цепочка, применять строго по порядку (B сделан поверх A, C поверх B, D поверх C);
  - `E-police.patch`, `F-recoil.patch`, `G-size-audit.patch` — независимые, от `main`.

Всё это есть и на GitHub (`chatgptpremium5656-lgtm/autobahn`), в ветках `cloud/A` … `cloud/G` и PR #1–#7. Подробное описание каждого задания, риски и ручные проверки — в описаниях PR.

## Как интегрировать

Вариант 1, через git — если проект это клон `autobahn`:
```
git fetch origin
git checkout -b integrate main
git merge origin/cloud/D   # включает A, B, C
git merge origin/cloud/E origin/cloud/F origin/cloud/G
```
В облаке эти слияния прошли без конфликтов.

Вариант 2, без git: из корня проекта `git apply patches/ALL-A-to-G.patch` или скопировать `files/` поверх проекта. Новые `.cs` файлы лежат вместе со своими `.meta`.

## Что проверить (обязательно)

1. Сборка Mac без ошибок компиляции.
2. Автотесты: запуск с `-driveQA -qaOutput <папка>`, все проверки `DriveValidation`, включая новую проверку полиции из E.
3. Ручные проверки из описаний PR. Самое рискованное:
   - **A, стриминг.** Нет дыр и провалов при езде на скорости, после рестарта, телепорта и выхода пешком. Время старта и память — сравнить с `main`. Первый запуск новой сборки строит весь остров ради картинки карты (как раньше), второй запуск берёт картинку из кэша.
   - **C.** Отбойники, заборы и припаркованные машины твёрдые, когда игрок рядом.
   - **D.** Плоские деревья вдали (`ForestRenderer.Billboards`, `BillboardRange`, `BoardTiling`); у машин трафика не пропали видимые детали при фильтре салона; режим «Мобильный» в меню паузы (ВЫСОКАЯ → БЫСТРАЯ → МОБИЛЬНАЯ).
   - **E, F.** Полиция, отдача и оружие в руке — по спискам в их PR.
4. **G** — только отчёт `SIZE_AUDIT.md`, ничего не удаляет. Применять его рекомендации отдельно и замерять сборку до и после.
