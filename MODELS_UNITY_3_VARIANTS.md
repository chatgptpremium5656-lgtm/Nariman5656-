# 3D-ассеты для Autobahn из Unity Asset Store: по 3 варианта

Все ассеты из Unity Asset Store. Лицензия магазина разрешает ставить их в свою игру, в том числе платную, указывать автора не нужно; нельзя только выкладывать сами файлы ассета.

Проверено через API магазина (30.09.2026): цена, оценки, таблица совместимости с рендер-пайплайнами и поле, где автор обязан указать использование ИИ. Ассеты с пометкой об ИИ исключены (так отсеялись Flora Pack, Caribbean Islands, Skog: Boreal).

Колонка «Пайплайн»: **URP · Unity 6** — автор проверил в нашей версии; **URP** — проверено в более старой Unity; **URP по описанию** — таблицы нет, но URP указан в описании; **Built-in** — материалы надо один раз перевести в URP (Window → Rendering → Render Pipeline Converter).

Как добавить в проект: получить ассет на странице, потом в Unity: Window → Package Manager → My Assets → Download → Import.

В каждой категории вариант 1 — рекомендуемый. Цены на момент проверки, скидки могут закончиться.
